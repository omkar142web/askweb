JavaScript is a programming language used to make websites and web applications interactive and dynamic.

For example, JavaScript can make a webpage:

Respond when you click a button

Validate a form

Show or hide content

Create animations

Update information without refreshing the page

Build interactive web apps like Gmail, Google Maps, and online games

How it fits into a website

The three main technologies are:

HTML → structures the webpage

CSS → controls how it looks

JavaScript → controls how it behaves

For example:

JavaScript
let name = "Alex";
console.log("Hello, " + name);

This tells JavaScript to store "Alex" in a variable and then print Hello, Alex to the console.

JavaScript originally ran mainly in web browsers, but today it can also run on servers, desktop applications, mobile apps, and more, using environments such as Node.js.

In short: JavaScript lets you program what happens on a webpage or application.
